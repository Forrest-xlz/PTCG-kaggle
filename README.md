# PTCG Competition Imitation Learning

The main project lives in `imitation_learning/`. It covers replay extraction, Transformer behavior-cloning training, standalone validation, exploratory data analysis, and Kaggle inference submission.

- [Quick start: environment, data, training, validation, and submission](imitation_learning/README.md)
- [Technical documentation](docs/README.md)

Run project commands from `imitation_learning/`. Supply the competition replays and model checkpoints yourself; default paths in the documentation do not imply that these resources are included in the repository.
